# Features & Status

| Feature | Status | Description |
| :--- | :--- | :--- |
| **Unified 3D Vertical World** | Done | Single continuous Three.js scene spanning sky, cloud deck, forest canopy, mountain valley, and stone bedrock. |
| **Procedural Damascus Blade** | Done | Double-edged diamond blade with fuller groove, wavy carbon steel banding, bronze quillons, leather grip, and pommel. |
| **Glowing Rune Etching** | Done | Elder Futhark runes along fuller groove that dynamically flare and shift color (Cyan $\rightarrow$ Frost Blue $\rightarrow$ Solar Amber $\rightarrow$ Molten Magma). |
| **Master Animation State Engine** | Done | Single GSAP ScrollTrigger timeline providing normalized `[0, 1]` progress and velocity without competing timelines. |
| **Continuous Sky Dome Shader** | Done | Custom GLSL shader with smooth Hermite interpolation between 5 atmospheric color checkpoints. |
| **Ascending Parallax Clouds** | Done | Soft volumetric cloud billboards that rush upward past the camera, creating high vertical speed sensation. |
| **Forest Canopy & Branches** | Done | Parallax pine silhouettes and gnarled branches emerging from mist and sweeping past viewport edges. |
| **Mountain Ridge Valley** | Done | Rugged low-poly 3D mountain crags emerging in dusk twilight. |
| **Impact Sequence Dynamics** | Done | Anticipation pause at 0.97, ground penetration, expanding ring shockwave, and 280-particle debris burst. |
| **Screen Shake Wrapper** | Done | Hardware-accelerated CSS transform matrix shake active during impact; disabled on `prefers-reduced-motion`. |
| **Synthesized Web Audio Engine** | Done | Pure Web Audio API atmospheric wind lowpass filter tied to velocity and sub-bass impact thud. |
| **Floating Narrative Overlay** | Done | Timed story text blocks anchored to alternating sides to keep blade in unobstructed view. |
| **Post-Impact Settled CTA** | Done | "The Journey Ends Here" CTA, specifications drawer, and smooth "Ascend Once More" button. |
| **Header HUD Controls** | Done | Audio mute/unmute toggle, act badge, and depth percentage meter. |
